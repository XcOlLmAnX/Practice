# Описание проекта «Карты дисциплин»

## Актуальность

Современные университеты сталкиваются с необходимостью регулярного обновления образовательных программ в соответствии с требованиями федеральных государственных образовательных стандартов (ФГОС ВО). Ручное ведение карт дисциплин трудоёмко и чревато ошибками. Проект «Карты дисциплин» решает эту проблему, предоставляя единую цифровую платформу для управления учебными планами.

## Цель проекта

Разработка и развитие веб-платформы для создания, хранения и проверки карт дисциплин образовательных программ Московского политехнического университета.

## Задачи

1. Обеспечить удобный интерфейс для создания и редактирования карт дисциплин.
2. Автоматизировать проверку соответствия учебных планов требованиям ФГОС ВО.
3. Организовать разграничение прав доступа между преподавателями, методистами и администраторами.
4. Реализовать экспорт карт в форматы Excel и PDF для официального документооборота.
5. Обеспечить мониторинг состояния платформы и своевременное устранение сбоев.

## Описание платформы

Платформа доступна по адресу [kd.mospolytech.ru](https://kd.mospolytech.ru/). Она включает:

- **Backend** — серверная часть, обрабатывающая бизнес-логику и работу с базой данных.
- **Frontend** — клиентская часть на базе Vue.js, реализующая интерфейс пользователя.
- **Мониторинг** — система Grafana для отслеживания состояния сервисов в реальном времени.
- **Документация** — регламент, устав проекта и инструкции для пользователей.

## Ожидаемые результаты

- Единая база карт дисциплин для всех направлений подготовки Московского Политеха.
- Автоматизированная проверка соответствия программ ФГОС ВО.
- Печатные формы карт дисциплин в форматах Excel и PDF.
- Сокращение трудозатрат методических отделов на ведение учебной документации.
