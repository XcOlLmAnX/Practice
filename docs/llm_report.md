# Отчёт по онлайн-курсам: Большие языковые модели (LLM)

## Пройденные курсы

### 1. Hugging Face NLP Course

- **Ссылка:** https://huggingface.co/learn/nlp-course
- **Формат:** онлайн, бесплатно
- **Язык:** английский
- **Объём:** ~20 часов

**Содержание курса:**

Курс охватывает полный цикл работы с современными NLP-моделями на базе библиотеки Transformers:

- Архитектура Transformer: механизм внимания (attention), энкодер и декодер.
- Предобученные модели: BERT, GPT-2, T5 — принципы работы и тонкая настройка (fine-tuning).
- Токенизация текста и работа с датасетами.
- Задачи NLP: классификация, генерация текста, ответы на вопросы, суммаризация.
- Использование Hub Hugging Face для загрузки и публикации моделей.

**Полученные знания:**

- Понял, как устроены трансформерные модели и почему они работают лучше рекуррентных сетей.
- Научился загружать предобученные модели и использовать их через pipeline API.
- Освоил токенизацию и батчинг данных для обучения.

---

### 2. Введение в большие языковые модели (Stepik)

- **Ссылка:** https://stepik.org/catalog?query=LLM
- **Формат:** видеолекции + практические задания
- **Язык:** русский
- **Объём:** ~8 часов

**Содержание курса:**

- Эволюция языковых моделей: от n-gram до GPT-4.
- Как работает генерация текста: temperature, top-k, top-p sampling.
- Промпт-инжиниринг: составление эффективных запросов, цепочки рассуждений (chain-of-thought).
- Ограничения LLM: галлюцинации, предвзятости, контекстное окно.
- Этические аспекты: ответственное использование ИИ, авторские права, приватность данных.

**Полученные знания:**

- Разобрался с параметрами генерации и научился влиять на «творческость» ответов модели.
- Освоил техники промпт-инжиниринга: few-shot, zero-shot, role prompting.
- Понял ограничения LLM и почему нельзя слепо доверять их ответам.

## Применение LLM при выполнении практики

В ходе практики большие языковые модели применялись непосредственно в разработке проекта:

### Чат-бот FitBot на GigaChat

В рамках вариативной части (Вариант 2.2) был разработан Telegram-бот **FitBot**, использующий GigaChat — российскую большую языковую модель от Сбер.

**Как используется LLM:**

1. **Генерация персонального рациона питания.** Пользователь вводит параметры (вес, рост, возраст, цель, активность), бот формирует структурированный промпт и передаёт его в GigaChat API. Модель возвращает подробный рацион на день из 5 приёмов пищи с калорийностью.

2. **Генерация утренней зарядки.** Каждое утро в 09:00 бот автоматически рассылает пользователям персональную программу упражнений, сгенерированную LLM на основе физических параметров.

3. **Подбор блюд из продуктов холодильника.** Пользователь перечисляет доступные продукты — модель предлагает 3 диетических рецепта с учётом пищевых ограничений.

**Пример промпта, используемого в боте:**

```
Ты профессиональный диетолог. Составь подробный рацион питания на один день.

Данные о пользователе:
- Имя: Николай
- Пол: мужчина
- Возраст: 19 лет
- Рост: 178 см
- Вес: 80 кг
- Цель: похудеть на −5 кг
- Уровень активности: Умеренно активный
- Целевые калории в день: 1950 ккал

Составь рацион из 5 приёмов пищи: завтрак, перекус, обед, перекус, ужин.
```

**Ключевые выводы:**

- Качество ответа LLM сильно зависит от чёткости промпта: добавление ограничений по формату значительно улучшает результат.
- Параметр `temperature` влияет на разнообразие ответов: при `temperature=0.8` рацион получается сбалансированным, при `1.0` — более творческим.
- Необходимо обрабатывать ошибки API (лимиты запросов, таймауты) и предусматривать повторные попытки.
