## Пройденные курсы

### 1. Hugging Face NLP Course

- **Ссылка:** https://huggingface.co/learn/nlp-course
- **Формат:** онлайн, бесплатно
- **Язык:** английский
- **Объём:** ~20 часов

**Содержание курса:**

Курс охватывает работу с современными NLP-моделями через библиотеку Transformers:

- Устройство архитектуры Transformer: механизм внимания (self-attention), многоголовое внимание.
- Разница между энкодерными моделями (BERT) и декодерными (GPT): когда применять каждую.
- Работа с токенизаторами: BPE, WordPiece, подготовка входных данных для модели.
- Pipeline API — быстрый способ использовать предобученные модели без погружения в детали.
- Тонкая настройка (fine-tuning) моделей на своих данных с помощью Trainer API.

**Полученные знания:**

- Разобрался в различиях между моделями для классификации, генерации и извлечения информации.
- Освоил Pipeline API для быстрого прототипирования NLP-задач.
- Научился работать с датасетами через библиотеку `datasets`: загрузка, фильтрация, батчинг.
- Понял, как токенизатор превращает текст в числа и почему важна длина контекста.

### 2. Введение в большие языковые модели (Stepik)

- **Ссылка:** https://stepik.org/catalog?query=LLM
- **Формат:** видеолекции + практические задания
- **Язык:** русский
- **Объём:** ~8 часов

**Содержание курса:**

- История развития языковых моделей: от n-gram до GPT-4 и далее.
- Механизм авторегрессионной генерации текста: как модель выбирает следующий токен.

### Использование Pipeline API для анализа текстов

В рамках изучения Hugging Face курса опробовал pipeline для анализа тональности текста (sentiment analysis) на примере отзывов о блюдах:

```python
from transformers import pipeline

classifier = pipeline("sentiment-analysis", model="blanchefort/rubert-base-cased-sentiment")
result = classifier("Рацион получился вкусным и сбалансированным!")
print(result)  # [{'label': 'POSITIVE', 'score': 0.98}]
```

**Ключевые выводы:**

- Качество ответа напрямую зависит от чёткости инструкций в промпте.
- few-shot примеры значительно улучшают форматирование вывода модели.
- При разработке интерфейса важно закладывать время ожидания: LLM-запросы занимают 3–10 секунд.
