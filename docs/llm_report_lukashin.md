## Пройденные курсы

### 1. Hugging Face NLP Course

- **Ссылка:** https://huggingface.co/learn/nlp-course
- **Формат:** онлайн, бесплатно
- **Язык:** английский
- **Объём:** ~20 часов

**Содержание курса:**

Курс посвящён практическому применению современных NLP-моделей:

- Архитектура Transformer с точки зрения потока данных: токены → эмбеддинги → attention → выход.
- Типы задач NLP: классификация текстов, NER, вопрос-ответ, суммаризация, генерация.
- Модели-энкодеры (BERT, RoBERTa) для задач понимания текста.
- Модели-декодеры (GPT-2, LLaMA) для задач генерации текста.
- Hugging Face Hub: поиск, загрузка и использование готовых моделей.

**Полученные знания:**

- Разобрался в том, как attention-механизм позволяет модели учитывать контекст при обработке каждого слова.
- Научился выбирать подходящую модель под конкретную задачу на основе её архитектуры.
- Освоил работу с Hugging Face Hub: поиск русскоязычных моделей, оценка их качества по метрикам.
- Понял разницу между предобучением и дообучением (fine-tuning) и когда каждое из них необходимо.

### 2. Введение в большие языковые модели (Stepik)

- **Ссылка:** https://stepik.org/catalog?query=LLM
- **Формат:** видеолекции + практические задания
- **Язык:** русский
- **Объём:** ~8 часов

**Содержание курса:**

- Эволюция языковых моделей: статистические модели → нейросети → трансформеры → LLM.
- Масштабирование: почему большие модели лучше и что такое emergent abilities.
- Промпт-инжиниринг: role prompting, chain-of-thought, few-shot примеры.
- RAG (Retrieval-Augmented Generation) — как подключить внешние знания к LLM.
- Этические проблемы: bias в данных, hallucinations, экологический след больших моделей.
- Российские LLM: GigaChat, YandexGPT, ruGPT — особенности и отличия от зарубежных аналогов.

**Полученные знания:**

- Понял почему у LLM возникают галлюцинации и как их минимизировать через чёткие инструкции.
- Разобрался с концепцией RAG и понял, как это решает проблему устаревших знаний модели.
- Изучил особенности российских LLM, в частности GigaChat — его сильные стороны в работе с русским языком.
- Осознал этические риски при внедрении LLM в продукты, которые видят конечные пользователи.

## Применение LLM при выполнении практики

В ходе практики полученные знания о LLM применялись в нескольких аспектах:

### Исследование GigaChat как инструмента для бота

Провёл сравнительный анализ возможностей GigaChat для задачи генерации рационов питания. Изучил документацию API и оценил:

- Качество генерации структурированного текста при разных значениях `temperature`.
- Ограничения по длине контекста и максимальному размеру ответа.
- Особенности работы с русскоязычными промптами по сравнению с англоязычными.

### Составление промптов для FitBot

Участвовал в разработке промптов для функции «Блюда из холодильника». Применял техники:

```
Промпт v1 (без структуры):
"Предложи блюда из этих продуктов: курица, яйца, помидоры"

Промпт v2 (с role prompting и форматом):
"Ты повар-диетолог. Предложи ровно 3 диетических блюда.
Для каждого: название, состав с граммовкой, калорийность, рецепт.
Нумеруй: 1️⃣, 2️⃣, 3️⃣. Не используй markdown."
```

Версия v2 давала значительно более структурированный и полезный результат.

**Ключевые выводы:**

- Явное указание роли («Ты повар-диетолог») заметно улучшает качество ответа.
- Ограничение формата вывода («не используй markdown») критично для Telegram, где разметка отображается иначе.
- Изучение российских LLM оказалось практически применимым — GigaChat хорошо понимает русский язык и культурный контекст при составлении меню.
