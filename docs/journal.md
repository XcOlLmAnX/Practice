# Журнал прогресса

## Запись 1 — 24 апреля 2026 г.

**Настройка среды и знакомство с Git**

Приступили к выполнению проектной практики. На первом этапе организовали рабочее пространство:

- Зарегистрировались на платформе GitVerse и приняли приглашение в «задание».
- Установили Git, настроили имя пользователя и email.
- Изучили базовые команды Git: `clone`, `add`, `commit`, `push`, `branch`, `merge`.
- Склонировали репозиторий задания на локальные машины.
- Ознакомились со структурой репозитория и разделили задачи между участниками команды.
- Определились с вариантом вариативной части: **Вариант 2.2 — реализация чат-бота на LLM**.

Первые коммиты с настройкой `.gitignore` и начальной структурой папок успешно отправлены на GitVerse.

## Запись 2 — 28 апреля 2026 г.

**Создание документации и начало работы над сайтом**

На втором этапе сосредоточились на Markdown-документации и вёрстке:

## Запись 3 — 5 мая 2026 г.

**Прохождение курсов по LLM и разработка чат-бота**

Третий этап был посвящён изучению больших языковых моделей и реализации вариативной части:

- Прошли онлайн-курс по NLP на Hugging Face и изучили основы архитектуры Transformer.
- Ознакомились с принципами промпт-инжиниринга и этическими аспектами применения ИИ.
- Начали разработку Telegram-бота FitBot на Python с использованием GigaChat API:
  - Настроили получение токена доступа через API GigaChat.
  - Реализовали основную логику бота: сбор параметров пользователя, расчёт калорий, генерация рациона.
  - Интегрировали базу данных SQLite для хранения профилей пользователей.
- Провели первичное тестирование бота на реальных запросах.
